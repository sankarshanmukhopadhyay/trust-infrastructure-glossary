# Semantic Model

TIG is more than a collection of definitions. It is a governed semantic system with distinct layers for meaning, classification, relationships, consumption and change control.

## The five-layer model

1. **Vocabulary** defines stable concepts, designations, definitions and provenance.
2. **Taxonomy** classifies canonical concepts through reviewed broader/narrower hierarchy.
3. **Ontology** projects typed semantic relationships between resolvable canonical concepts.
4. **Profiles and artifacts** expose bounded and machine-readable consumption surfaces.
5. **Governance** controls admission, change, provenance, validation and publication.

These layers are deliberately separate. The vocabulary is not replaced by the taxonomy; the ontology does not become a new normative specification; and generated artifacts do not outrank their governed sources.
