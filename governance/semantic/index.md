# Semantic Change & Authoring

This section governs **how maintainers change TIG semantics**. It covers concept identity, designations, relationships, taxonomy assertions, provenance and authoring discipline.

For a consumer-facing explanation of vocabulary, taxonomy and ontology, use the first-class [Semantic Model]({{ '/semantic-model/' | relative_url }}).

Maintainer changes must preserve stable concept identity, explicit provenance, descriptive-vs-normative authority boundaries, deterministic generation and backward compatibility unless a breaking release explicitly says otherwise.
